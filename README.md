# سواك — موقع عيادة أسنان مع حجز أونلاين

موقع عربي (RTL) لعيادة **سواك** لطب وتجميل الأسنان، يتيح للمريض:

1. اختيار الخدمة ← الطبيب ← اليوم والوقت المتاح فعلياً.
2. تأكيد رقم الجوال برمز تحقق (OTP) يصله برسالة SMS.
3. دفع **عربون** إلكترونياً (يُخصم من قيمة الجلسة).
4. استلام **رسالة تأكيد** على الجوال فور الدفع، ثم **تذكير** قبل الموعد بيوم.

ويحتوي على **لوحة تحكم** للعيادة (`/admin`) لعرض المواعيد وتغيير حالتها (حضر / لم يحضر / إلغاء مع إرسال رسالة للمريض).

---

## التشغيل محلياً

يتطلب Node.js 22.13 أو أحدث (يستخدم قاعدة SQLite المدمجة في Node، بدون أي مكتبات أصلية).

```bash
npm install
cp .env.example .env     # اختياري للتجربة
npm run dev
```

ثم افتح:

- الموقع: http://localhost:3000
- الحجز: http://localhost:3000/book
- لوحة التحكم: http://localhost:3000/admin (كلمة المرور الافتراضية محلياً `admin`)

في وضع التطوير:
- `SMS_PROVIDER=console` ← الرسائل (ومنها رمز التحقق) تُطبع في الطرفية.
- `PAYMENT_PROVIDER=mock` ← صفحة دفع تجريبية لا تخصم أي مبلغ.

### الاختبارات

```bash
npm test
```

## تعديل بيانات العيادة

كل بيانات العيادة في ملف واحد: [`src/clinic.js`](src/clinic.js)

- الاسم، الهاتف، واتساب، العنوان، رابط الخريطة.
- ساعات الدوام لكل يوم (الجمعة مغلق افتراضياً).
- الخدمات: المدة، السعر الابتدائي، **قيمة العربون** لكل خدمة.
- الأطباء: الخدمات التي يقدمها كل طبيب وأيام دوامه.
- مدة الخانة الزمنية، أقصى مدة للحجز المسبق، سياسة الإلغاء.

> ⚠️ أسماء الأطباء الحالية تجريبية — استبدلها بالأسماء الحقيقية.

## الرسائل النصية (SMS)

مدعوم حالياً: **Twilio** (يعمل في الأردن وفلسطين والخليج).

```env
SMS_PROVIDER=twilio
TWILIO_ACCOUNT_SID=ACxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxx
TWILIO_FROM=SIWAK          # أو رقم هاتف، أو استخدم TWILIO_MESSAGING_SERVICE_SID
```

لإضافة مزوّد محلي (مثل Unifonic أو شركات الاتصالات المحلية) أضف مزوّداً جديداً في
[`src/sms/index.js`](src/sms/index.js) يطبّق الدالة `send(to, body)` فقط.

نصوص الرسائل في [`src/messages.js`](src/messages.js).

الرسائل التي يرسلها النظام:

| متى | الرسالة |
|---|---|
| عند طلب رمز التحقق | رمز من 6 أرقام صالح 10 دقائق |
| بعد دفع العربون | تأكيد الموعد + رقم الحجز + المبلغ المدفوع |
| قبل الموعد بـ 24 ساعة | تذكير بالموعد |
| عند الإلغاء من لوحة التحكم | إشعار إلغاء |

## الدفع (العربون)

| المزوّد | متى تستخدمه |
|---|---|
| `tap` — [Tap Payments](https://www.tap.company) | الأردن ودول الخليج (فيزا، ماستركارد، مدى، Apple Pay…) |
| `stripe` — [Stripe Checkout](https://stripe.com) | إذا كان حساب العيادة في دولة يدعمها Stripe |
| `mock` | للتطوير فقط (يُرفض تشغيله في الإنتاج) |

**Tap:**
```env
PAYMENT_PROVIDER=tap
TAP_SECRET_KEY=sk_live_xxx
```

**Stripe:**
```env
PAYMENT_PROVIDER=stripe
STRIPE_SECRET_KEY=sk_live_xxx
STRIPE_WEBHOOK_SECRET=whsec_xxx
```
وأضف Webhook في لوحة Stripe على الرابط `https://YOUR-DOMAIN/api/payments/stripe/webhook` للحدث `checkout.session.completed`.

### كيف يعمل الحجز بأمان

- عند الضغط على "تأكيد والانتقال للدفع" يُحجز الموعد **مؤقتاً** لمدة `HOLD_MINUTES` (افتراضياً 30 دقيقة) ولا يظهر لغير المريض.
- لا يُعتمد على رابط الرجوع من بوابة الدفع وحده؛ الخادم يسأل بوابة الدفع مباشرة عن حالة العملية قبل تأكيد الموعد.
- إذا انتهت مدة الحجز المؤقت يُحرَّر الموعد تلقائياً.
- إذا وصل الدفع متأخراً وكان الموعد قد حُجز لشخص آخر، يُعلَّم الحجز "دفع بحاجة لمراجعة" في لوحة التحكم ويُبلَّغ المريض أن العيادة ستتواصل معه.

## النشر (Production)

أي استضافة تدعم Node.js مع قرص دائم لملف قاعدة البيانات (مثل Render, Railway, Fly.io, أو VPS):

```env
NODE_ENV=production
BASE_URL=https://siwak.example.com
SESSION_SECRET=<openssl rand -hex 32>
ADMIN_PASSWORD=<كلمة مرور قوية>
SMS_PROVIDER=twilio
PAYMENT_PROVIDER=tap
DB_PATH=/var/data/siwak.db
```

```bash
npm ci --omit=dev
npm start
```

- شغّل الموقع خلف HTTPS (مطلوب لبوابات الدفع ولحماية كوكي لوحة التحكم).
- خذ نسخة احتياطية دورية من ملف قاعدة البيانات.
